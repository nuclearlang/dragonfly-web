# Dialect `react`: the web platform in TypeScript

What this dialect adds to the platform's sheet: the app is generated as React 19 (no JSX) + React Router 7 + Vite +
Vitest in `build/app` (never edit it). `dragonfly build`, `dragonfly install` (npm), `dragonfly run` (Vite),
`dragonfly test` (Vitest + Testing Library). Full rules: `nuclear help react`.
